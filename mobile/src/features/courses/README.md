# CM-002 本机课程与交互样例

从仓库根运行 `npm.cmd --prefix mobile run dev -- --host 127.0.0.1 --port 5174 --strictPort`，打开 `http://127.0.0.1:5174/course-preview.html`。

主应用入口为工作台“我的课程”→`/courses`，由路由懒加载，按当前身份读取和保存本机课程。`course-preview.html` 保留为独立 Vite 内存样例入口，未单独配置为生产构建入口。品牌文案使用有绪 CampusWeave。

- 列表按学期筛选；同名课程按独立 ID 区分，不按名称合并。
- 详情包含总览、课程要求、任务、资料；后两区明确未查询真实数据。
- 可新增样例、编辑档案和简单小组说明；档案编辑按顺序保留名称、学期、教师、地点和小组旧值，未改变内容的保存不增加历史。要求支持六类常用字段、自定义字段、四种状态、来源和旧值历史。
- 主应用编辑采用主动保存；取消不写入。Workspace v3 的 `courseProfiles` 保存档案、要求、自定义字段和旧值历史，已有 `courses` 继续承载旧课表，不自动建立 Task／时间规则／资料关联。
- IndexedDB 仍使用原有数据库和 object store；v3 是记录版本。v1/v2 读取时转换到内存，首次显式保存通过同一 revision 事务写回，不在读取过程中改写旧数据。陈旧版本拒绝写入，保留草稿；可读取最新记录后核对再保存。
- 账户数据按 owner 分区，未登录身份使用既有 `offline` 分区。切换身份清空旧草稿；退出登录沿用删除当前账户 Workspace 的策略，退出前提示备份。不会自动上传、跨设备同步或保证浏览器清理后的恢复。
- `courseModel.ts` 复用编辑逻辑，`courseRecords.ts` 校验持久化记录；`demoModel.ts` 仅提供合成样例，绝不用于初始化账户资料。独立样例编辑仅在内存中生效，刷新重置。
- 要求编辑可在快捷与完整方式间切换，同一份未应用草稿保持不变；完整方式提供多行编辑和修改前/本次输入对照。两种方式均保留四态与依据校验，取消不修改原记录，相同内容保存不追加历史。要求与依据各限 2000 字，保存后保留换行。

记录校验上限为 100 门课程、每课 100 项要求、每档案／要求 500 条旧值历史，超过上限拒绝保存，不静默裁剪。沿用界面字段长度：名称／教师 100、学期／自定义标签 60、地点 200、小组 1000，要求及依据各 2000 字。依据文字是用户声明，尚未验证教师原文，不当作服务端 EvidenceRef。

验证：`npm.cmd --prefix mobile test -- src/features/courses/demoModel.test.ts src/features/courses/coursePersistence.test.ts src/services/clientWorkspace.test.ts src/services/timetable.test.ts`；全项目类型/构建检查用 `npm.cmd --prefix mobile run build`。浏览器交互另见成员 C 的工作记录。

备份导出包含课程档案与历史，不包含原文件。课程恢复预览归 CM-003，本期禁止导入含课程档案的备份，或用直接恢复覆盖已有课程；原无课程资料的旧备份仍可按原入口恢复。备份格式升级后旧版本 App 不能读取，请保留兼容的 App 版本。
