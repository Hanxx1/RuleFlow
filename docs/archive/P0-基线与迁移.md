## 可复现环境矩阵

- Node 24.15.0 / npm 11.12.1；Vue/Vite/Capacitor 6 锁在 `mobile/package-lock.json`。
- Java 21.0.5；Android SDK 34、Build Tools 34、Platform Tools 与 Gradle 8.2.1 已安装在 E 盘，`assembleDebug` 已通过。
- Python 3.12 便携运行时和解析/OCR 依赖已安装在 E 盘，后端测试已通过。
- macOS/Xcode、CocoaPods、iOS 签名资料不可用，IPA 只能交付工程。
- DevEco Studio/HarmonyOS SDK/设备不可用，HAP 构建 blocked。

## 数据迁移原则

旧 `localStorage` 中 `zhishi-profile` 与 `zhishi-tasks` 仅导入本机分区；样例永不自动迁入账户。旧 Demo JSON 通过 `case_kind=demo` 和 `workspace=demo` 保留。新账号写入 `owner_id`，所有读取都必须带所有者过滤。
