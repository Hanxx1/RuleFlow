## 1. 现状检查

- 真实入口为 `mobile/src/features/planning/PlanView.vue` → `/plan?tab=schedule` → `PlanSchedule.vue`。父页面受事项列表/加载状态限制；无事项账户当前无法进入子页面，新增样例入口必须考虑这一点。
- `PlanSchedule.vue` 已有周导航、选日、课程/忙碌/任务图例，但用 `dayItems` 按开始日过滤后展示列表，没有小时轴和时间长度定位；跨日项目不会显示在次日。既有起始日期和“今天”使用浏览器本地日期。
- `ClientCalendarPanel.vue` 展示本机课表及离线算法结果，与账户日程是不同数据流。里面的起始日期不是账户排程窗口，不将这两处复用成同一隐式状态。
- `style.css` 存在schedule-timeline/hour样式（每小时42px），当前PlanSchedule未使用；不能把已有CSS当网格已完成。
- `AppBottomSheet.vue` 可复用详情容器，支持对话框标签、初始聚焦与Esc关闭；焦点返回触发按钮仍需本切片验证/补齐。
- RF-043过时草案恢复刚完成，固定样例不能接入makePreview/confirmDraft/save/remove/lock，也不能被这些账户操作提交。

依据：[CM-005任务卡](../../plans/SPRINT_01_TASKS.md)、[唯一决策表](D_public_interface_questions.md)。Q04/Q08-d与CM-006仍阻塞真实关联/去重；本切片可独立进行。

## 3. 最小交互与隔离

1. 在原“日程安排”入口提供显式“查看时间网格样例”入口，进入后持续标“固定样例 · 不保存到账户”，提供“返回日程”。展示样例时不挂载账户PlanSchedule，避免其watch加载/写操作；父层只做必要分支，空事项状态也能打开样例。默认不切走现有账户页面，不用请求失败触发样例兜底。
2. 样例包装组件只消费静态fixture及内存视图状态；不调用API、不读写Workspace/本机资料、不触发排程算法。离线/未登录均可打开；已有离线演示保留。入口并非新的课程管理页。
3. 默认**日视图**；顶部“日/周”切换、前后导航、日期/范围标题。日导航±1天，周导航±7天，周从周一开始。视图切换保留选中日期，点周标题某日可进入该日日视图。
4. 固定样例锚点为2026-11-09（周一）；用“回到样例周”定位该周/该日，不将历史样例伪称“今天”，不把fixture平移到真实日期。跨月/跨年可导航，没数据保留空网格和“当天/本周没有样例安排”。
5. 时间轴覆盖00:00–24:00、每小时60px，半小时辅助线；初次打开滚到08:00附近。网格独立纵向滚动、约60vh可视高；顶部日期与左侧时间轴固定。周视图7列，日列最小112px，**只在网格内横向滚动**，页面本身不横向溢出。字体不为强塞七列而缩小。
6. 来源用颜色＋文字标签区分课程/任务/忙碌。标题截断但有完整可访问名称；点击/Enter/Space打开只读详情，展示完整起止、跨日提示、来源和样例依据。课程展示合成课程详情（如同一课程两条时间记录），不跳不存在的真实详情URL；真实路由由C后续提供。
7. 所有样例带可解析的合成依据记录，明确“样例输入依据”；不编造官方事实。缺失引用样例显示“待核对”，详情不显示有效证据标记。展示层字段仅是内部视图模型，不写shared Schema/API，不作为Q01/Q02课程契约定稿。

## 4. 时间与重叠布局

- 视图统一 **Asia/Shanghai**，与本机课表既有口径一致；显式offset按绝对时刻转换后展示，不用浏览器默认时区决定列。该显示建议不重新定义任务deadline或课程规则协议。
- 输入为已展开的时间段（类似现有Schedule的id/title/kind/starts_at/ends_at），可附只读合成course引用和依据；不在网格内展开规则、推导截止或写占用。fixture ID按发生时段唯一，同课不等于同一时段。
- 先与显示日期范围求交，再按上海午夜切成显示片段；片段保留原item ID及完整起止。跨日只增加显示片段，不复制业务对象。结束恰为00:00时不生成次日零长度块；零长、反向或非法时间显示数据异常提示，不参与布局。
- 垂直位置=距当日00:00分钟数×1px；高度=当日可见持续分钟数×1px。视觉最小高度不能改变真实时长/冲突；小于44px的短块可保留真实高度，并提供同日可聚焦/可触摸的时段索引（44px行高）用于打开详情，避免扩展热区互相遮挡。
- 冲突采用半开区间 `[start,end)`，首尾相接不冲突。按起点、终点、稳定ID排序，以扫线分配空闲列；每个连通重叠组按最大并发列数分宽，重叠片段都可见，显示“时间重叠”而非资格/算法不可行结论。
- 每个重叠列保留至少44px点击宽度和间距；必要时扩大所在日期列，在网格内滚动，不静默压住事件。三重重叠、包含关系、链式重叠均要测试，结束后释放列。同标题/同时间不同ID不去重；真实跨端唯一占用属于CM-006。
