## 本轮代码修正

- HTML 正文保留段落和内联文字，避免日期被标签拆断；支持日期中的空格和日期在前、截止用途在后的句式。
- LLM 请求加入共享 JSON Schema、画像字段与禁止映射示例；校验引用及原文逐字证据。
- 数字规则必须匹配引用的局部语义；教师人数、参赛次数、学院指标不能冒充学生人数或排名条件。
- 非法但有真实证据的规则转为 unsupported_conditions；缺乏可信证据则拒绝响应。合法任务可保留。
- 原文中无法建模的资格条件阻止整体 TRUE，移动端显示需核对条件。

## 调度算法

规则匹配使用白名单 AST 和 TRUE/FALSE/UNKNOWN 三值逻辑。排程采用 DAG 拓扑约束与贪心可用时段分配，优先级 = 0.40×紧迫度 + 0.30×重要度 + 0.15×后续依赖比例 + 0.15×用户偏好。紧迫度为 1/(1+剩余天数/7)，过期任务单独拒绝。

排程遵守截止时间、前置任务完成时间、工作时段、已有日程、缓冲时间、每日任务上限和拆分配置。草案经用户确认后原子提交并检测状态变化。DeepSeek 负责候选理解，不直接决定资格、执行规则或保存日程；此算法不保证全局最优。

## 验证及边界

后端135项、前端42项测试通过，类型检查通过。真实 HTTP 移动视口已跑通注册登录、上传确认、分析、任务确认、排程保存；该浏览器链路使用本地解析，不等于安卓真机 DeepSeek 全链路验证。

`scripts/test-public-notice-file-formats.py` 将公开正文转为清晰 PNG 和原生文本 PDF，实际 OCR/解析各得到6条带坐标文本与4个截止日。它们是生成的测试文件，不是学校原始附件。PDF 换行若将日期与用途拆开，日期用途仍可能 UNKNOWN；清晰文字测试不证明模糊照片、复杂表格、手写和跨页解析效果。

仍需完善：每个任务独立截止日期的确认与保存、更多资格画像字段及证据、复杂原始附件评测、安卓真机分享和在线模型全链路。三份样本不能支持识别准确率结论。
