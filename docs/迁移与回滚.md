# 迁移与回滚

- 当前 SQLite 表由启动时的幂等 `CREATE TABLE IF NOT EXISTS` 建立，适用于单实例演示；发布前迁移 PostgreSQL 时必须引入版本化迁移并做回滚演练。
- 旧 `localStorage` 的 `zhishi-profile`、`zhishi-tasks` 只属于本机空间，不自动上传或并入账号。
- Demo 永远从 `shared/demo` 只读加载，不写入账号数据库。
- 部署升级前停止写入并备份 `/data/ruleflow.db`；校验备份可打开、表数量与行数后再升级。
- 若升级失败，停止新容器、恢复数据库卷快照并回退到上一镜像；不得用清库作为回滚。
- 同步删除使用 tombstone，客户端重放需带更高版本；发生冲突时保留服务端版本并返回冲突，不静默覆盖。
