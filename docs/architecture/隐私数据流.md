# 隐私数据流

1. 文字输入先在前端本地做身份证号、手机号、银行卡号模式遮盖并展示预览。
2. Android 分享文件先经 `ContentResolver` 在后台复制到 App 私有目录，只进入 pending 队列，不自动上传。
3. 用户明确勾选同意后，账户模式才把选定来源发往后端；后端按 owner 隔离并建立不可伪造的 EvidenceRef。
4. URL 在同意前不会访问；同意后逐跳校验协议、DNS/IP、重定向与体积，拒绝内网、回环和 link-local。
5. 当前图片/扫描 PDF OCR 在自部署后端本地执行。因此只能声称“自部署服务内 OCR”，不能声称图片从未离开手机。严格端侧图片 OCR 尚未验收。
6. Rule AST 只引用 `profile.*` 必需字段；字段缺失返回 UNKNOWN。Demo、本机画像和账户画像分区存放。
7. 生产环境禁止默认 pepper、开发验证 token、调试签名和真实用户样本进入仓库；日志不得记录原文、密码或令牌。

用户可通过画像页修改事实；完整的数据导出、账户删除和对象存储生命周期仍属于发布前阻塞项。
